# Web UI 中英文切换 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 CodeGraph Web UI 提供默认中文、可持久化的中英文切换，并将所有前端可控的固定文案纳入词典。

**Architecture:** 新建一个 Svelte 响应式 i18n 模块，集中保存两份语义化文案词典、语言状态和本地存储读写。所有视图、组件与前端模型通过 `t()` 取得可见固定文案；顶栏只负责调用语言切换，不保存第二份状态。

**Tech Stack:** Svelte 5 runes、TypeScript、Vitest、Vite、svelte-check。

**Spec:** `docs/superpowers/specs/2026-09-04-web-ui-i18n-design.md`

## Global Constraints

- 只翻译前端可控的用户可见文案和可控提示；API 原始错误、项目/路径/文件/符号/代码内容保持原样。
- 支持 `zh-CN` 与 `en`；首次或无效保存值默认 `zh-CN`。
- 仅用内置词典，不引入第三方国际化依赖。
- 产品名 `CodeGraph` 和语言切换控件中的 `EN` 不是待翻译的遗留英文。
- 语言改变必须立即更新界面；本地存储不可用时仍能完成当前会话切换。

- [ ] **Step 3: 实现最小 i18n 模块**

```ts
export type Locale = 'zh-CN' | 'en';
type TranslationKey = keyof typeof translations['zh-CN'];

const storageKey = 'codegraph.ui.locale';
const translations = {
  'zh-CN': { 'nav.map': '地图', 'outline.showing': '显示 {shown} / {total} 个符号。' },
  en: { 'nav.map': 'Map', 'outline.showing': 'Showing {shown} of {total} symbols.' },
} as const;

let locale = $state<Locale>(readLocale());

export const i18n = {
  get locale() { return locale; },
  setLocale(next: Locale) { locale = next; try { localStorage.setItem(storageKey, next); } catch {} },
  t(key: TranslationKey, values: Record<string, string | number> = {}) {
    return translations[locale][key].replace(/\\{(\\w+)\\}/g, (_, name) => String(values[name] ?? `{${name}}`));
  },
};
```

将示例词典扩展为本计划后续任务列出的全部 UI 语义键；`readLocale()` 只接受 `zh-CN` 和 `en`，并在存储不可读时返回 `zh-CN`。`assertTranslationKeys()` 比较两份词典的排序键数组，发现差异时抛出错误。在 `vitest.workspace.mts` 的 UI 项目中将 `__tests__/ui-i18n.test.ts` 加入 `test.include`，使这个使用 `.svelte.ts` runes 的模块在现有 Svelte 插件与 jsdom 环境中编译和运行。

```ts
import { readFile, readdir } from 'node:fs/promises';
import { join } from 'node:path';
import { describe, expect, it } from 'vitest';

const copy = />(?:\\s*)(Loading|Nothing|Could|Showing|Search|Save|Export|Copy|Back|Outline|Callers|Callees|Source|Entry|Map|Flow|Dead|Live|Index)\\b/;

async function svelteFiles(directory: string): Promise<string[]> {
  const entries = await readdir(directory, { withFileTypes: true });
  const nested = await Promise.all(entries.map(async (entry) => {
    const path = join(directory, entry.name);
    return entry.isDirectory() ? svelteFiles(path) : path.endsWith('.svelte') ? [path] : [];
  }));
  return nested.flat();
}

describe('Web UI copy audit', () => {
  it('没有遗留的模板固定英文文案', async () => {
    const files = await svelteFiles('ui/src');
    const sources = await Promise.all(files.map((file) => readFile(file, 'utf8')));
    expect(sources.flatMap((source) => source.split('\\n')).filter((line) => copy.test(line))).toEqual([]);
  });
});
```
